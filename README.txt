معماري بيتا — حزمة PWA

الرفع:
1. فك الضغط وارفع محتويات المجلد مباشرة إلى موقع HTTPS مثل Netlify.
2. لا ترفع ملف ZIP كصفحة ويب منفردة؛ ارفع المجلد أو استخدم نشر Netlify بالسحب.
3. افتح رابط الموقع. على Android: القائمة > تثبيت التطبيق.
   على iPhone: Safari > مشاركة > إضافة إلى الشاشة الرئيسية.
4. لتفعيل المشاريع السحابية: نفّذ supabase-setup.sql داخل SQL Editor
   لمشروع Supabase المحدد في index.html.
5. اضبط إعدادات Supabase Auth والبريد حسب احتياجك.
6. بدون اتصال بالإنترنت يمكن فتح التطبيق بعد تحميله أول مرة وحفظ مشاريع محلية.
   الحسابات السحابية تتطلب اتصالًا.

الملفات:
index.html - التطبيق
manifest.webmanifest - بيانات PWA
sw.js - التخزين المؤقت
icon-192.png / icon-512.png - أيقونة من الصورة المرفقة
mimari-preview.jpg - الصورة الأصلية
supabase-setup.sql - جدول المشاريع وسياسات حماية المستخدمين

تنبيه: هذا تطبيق تخطيط أولي ثنائي الأبعاد وليس برنامج تصميم إنشائي معتمد.
هذه نسخة مستقلة معاد بناؤها بالهوية نفسها، وليست نسخة مطابقة حرفيًا لكل سطر
من الكود الطويل الوارد في المحادثة. بعض الأدوات المتقدمة تحتاج اختبارًا إضافيًا.
