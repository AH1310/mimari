توضح هذه السياسة كيفية التعامل مع البيانات عند استخدام تطبيق معماري وموقعه الإلكتروني.

البيانات الشخصية

لا يتطلب معماري إنشاء حساب، ولا يطلب من المستخدم إدخال اسمه أو بريده الإلكتروني أو تقديم صور شخصية أو موقعه الجغرافي.

بيانات الاتصال والاستضافة

يُستضاف موقع معماري على GitHub Pages. عند فتح الموقع، قد يعالج مزود الاستضافة بيانات تقنية مرتبطة بالاتصال، مثل عنوان الإنترنت، لأغراض تشغيل الخدمة وأمانها. تخضع معالجة هذه البيانات ومدة الاحتفاظ بها لسياسة خصوصية GitHub.

الاطلاع على سياسة خصوصية GitHub

التواصل عبر البريد الإلكتروني

إذا تواصلت معنا عبر البريد الإلكتروني، فسنتلقى عنوان بريدك ومحتوى رسالتك وأي مرفقات ترسلها. نستخدم هذه المعلومات للرد على استفسارك ومعالجة طلبك. يرجى عدم إرسال معلومات حساسة غير ضرورية.

الاحتفاظ بالبيانات وحذفها

لا ينشئ التطبيق حسابات مستخدمين تحتاج إلى حذف. تُحتفظ بمراسلات الدعم بالقدر اللازم لمعالجة الطلب ومتابعته، أو للوفاء بالتزامات قانونية واجبة. يمكنك طلب حذف مراسلاتك عبر بريد التواصل أدناه. أما بيانات الاستضافة فتخضع لإجراءات مزود الاستضافة وسياسة الاحتفاظ الخاصة به.

الروابط الخارجية
